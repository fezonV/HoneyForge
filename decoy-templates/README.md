# Рабочие страницы архива

`archive.html` — серверная адаптация компонентов `frame`/`catalog` из
`tools/decoy-lab/templates/shared.js`, состояний `low.js` и `medium.js`.
`archive.css` скопирован из `tools/decoy-lab/assets/archive.css` (версия на
`3511383`) и дополнен стилями ссылок/форм и трёхколоночного каталога без даты:
дата отсутствует в ProfileConfig, поэтому не выдумывается.

Владельцу шаблонов: изменения оформления сначала сверяйте с этими исходниками;
в рабочую копию переносите нужные CSS/структурные правки, сохраняя серверные формы.
Лаборатория остаётся автономной и не изменена. Её fixture, editor, JavaScript,
readonly/disabled вход и переключатели состояний в бинарник не включаются.

Пакет встраивается в `cmd/decoy` через `go:embed`; файловый сервер хоста не нужен.
`internal/decoy/pages.go` строит View из фактически применённого ProfileConfig.
Go `html/template` экранирует текст, содержимое и URL. JS, CDN и запросов к центру
нет. Стили доступны только по `/assets/archive.css`.

Маршруты: POST `/login`, POST `/logout`, GET `/files`, GET/POST `/console`.
Авторизация и события выполняются сервером до выдачи успешного результата.
Без Accept `text/html` существующие JSON/plain-text ответы сохраняются.
В браузере `/files?path=...&view=1` открывает просмотр, `download=1` — вложение;
Low показывает только каталог. Формы ошибок входа, истечения сессии, пустого
каталога, неизвестного файла и недоступности используют общую оболочку.
