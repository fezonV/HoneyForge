# Рабочие страницы архива (FE1-04)

Интеграционные шаблоны и стили рабочей приманки, адаптированные из лаборатории `tools/decoy-lab/` (TL-01) для эмулятора decoy (BE-03).

## Архитектура и шаблоны
- `archive.html` — серверный Go-шаблон (`html/template`) страниц архива для уровней Low и Medium.
- `archive.css` — автономные локальные стили без внешних CDN, аналитики и шрифтов.
- `templates.go` — Go-пакет со встраиванием ресурсов (`go:embed`) и типобезопасной структурой `View`.

## Поддерживаемые состояния и маршруты
| Состояние | Маршрут | Описание |
|---|---|---|
| `login` | `GET /login`, `POST /login` | Форма аутентификации (Medium) с серверной проверкой учётных данных |
| `catalog` | `GET /`, `GET /files` | Каталог доступных документов архива |
| `file` | `GET /files?path=...&view=1` | Просмотр содержимого файла из fake-FS с метаданными и кнопкой возврата |
| скачивание | `GET /files?path=...&download=1` | Скачивание файла в виде вложения (`Content-Disposition: attachment`) |
| `console` | `GET /console`, `POST /console` | Псевдоконсоль архива с выполнением команд (`pwd`, `ls`, `cat`) |
| `logout` | `POST /logout` | Серверный отзыв сессии и сброс cookie |
| `empty` | `GET /files` | Состояние пустого архива без документов |
| `unavailable` | `GET /files?path=...&view=1` | Статический отказ для Low-приманки (публикует только каталог) |
| `not-found` | Любой неизвестный путь | 404-страница «Документ не найден» |
| `stopped` | Любой путь при остановленном сервисе | 503-страница «Сервис временно недоступен» |

## Безопасность и экранирование (FR-A1, FR-A2, MASK-4)
- Все пользовательские и профильные данные экранируются движком `html/template`.
- Отсутствуют токены, management URL, служебные комментарии и явные маркеры C2/honeypot.
- Доступ к защищённым страницам и действиям Medium возможен строго при наличии валидной серверной сессии.
- Псевдоконсоль и операции с файлами изолированы в памяти и синтетическом fake-FS; доступ к ОС и реальной файловой системе исключён.
