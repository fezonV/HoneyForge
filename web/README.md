# HoneyForge Operator Console (`web/`)

Фронтенд-интерфейс единого центра управления реалистичными honeypot-ловушками HoneyForge (Хакатон UmirHack).
Реализация задачи **[FE-01] Каркас оператора, shared UI, API-клиент и авторизация (P0)**.

---

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
cd web
npm install
```

### 2. Запуск локального сервера разработки
```bash
npm run dev
```
Интерфейс доступен по адресу: **`http://127.0.0.1:5173`**

### 3. Сборка для продакшна (Nginx)
```bash
npm run build
```
Собранные статические файлы размещаются в каталоге `web/dist/`. Конфигурация для Nginx находится в [`web/nginx.conf`](./nginx.conf).

## 🛡️ Архитектура и функционал

- **Дизайн-система:** Корпоративная светлая тема SOC (чистые поверхности `#ffffff`, глубокий кибер-синий `#0284c7`, статусные индикаторы угроз, доступность фокуса клавиатуры).
- **Разделы навигации:**
  - **«Обзор» (`/` или `#overview`):** Сводные KPI-карточки (ловушки Low/Medium, атаки за 24ч, топ IP) и живая лента инцидентов.
  - **«Профили» (`#profiles`):** Реестр профилей (порты, баннеры, маскировка канала, jitter, скрытое имя процесса) с CRUD.
  - **«Ловушки» (`#traps`):** Реестр парка (статусы `Online` / `Offline` / `Last-seen`), ревизии, генерация одноразовых Enrollment токенов.
  - **«События» (`#events`):** Полноразмерный журнал атак с фильтрацией по риску, типу, поиском, экспортом IoC (CSV) и инспектором телеметрии.
  - **«Аудит» (`#audit`):** Журнал безопасности с историей операций операторов.
- **Инспектор телеметрии (`AttackInspector`):**
  - Детальный просмотр перехваченных учетных данных (honeytokens), команд во fake filesystem, HTTP-запросов и сетевых параметров.
  - Все недоверенные данные атакующего рендерятся безопасно (без HTML/Script инъекций).
- **Аутентификация & Роли (FR-C5):**
  - Авторизация оператора через защищенные cookie сервера + заголовок `X-CSRF-Token` (без хранения токенов в `localStorage`).
  - Разграничение ролей:
    - **`operator`:** Полный доступ (создание профилей, генерация токенов, запуск/остановка ловушек).
    - **`viewer`:** Режим наблюдателя (действия изменения скрыты/заблокированы, секреты enrollment недоступны).
  - Пресеты для демо:
    - Оператор: `soc_operator` / `HoneyForge2026!`
    - Наблюдатель: `soc_viewer` / `ViewerPass2026!`
- **Режим фикстур (BE-01):**
  - В шапке доступен переключатель между автономными фикстурами контракта BE-01 и боевым API (`/api`).
  - При сбое реального бэкенда интерфейс честно показывает ошибку связи (503/Network Error), не подменяя её фейковыми данными.
