# Лаборатория шаблонов Low / Medium

Автономный статический инструмент для задачи [#18](https://github.com/fezonV/HoneyForge/issues/18). Работает без основного Go-сервера, центра, агента, авторизации и frontend-сборки. Нужен современный браузер с JavaScript; для приведённой команды — Python 3. Установка пакетов не требуется.

## Запуск

Из корня репозитория:

```sh
python3 -m http.server 8092 --bind 127.0.0.1 --directory tools/decoy-lab
```

Открыть <http://127.0.0.1:8092/>. Остановить сервер: `Ctrl+C`. Если порт занят, заменить `8092` свободным портом. При запуске из этого каталога используйте `--directory .`. Открытие через `file://` не поддерживается: браузер должен загружать локальные ES-модули через HTTP.

Этот HTTP-сервер обслуживает только лабораторию. Go-приложение перезапускать не требуется; после правок лаборатории достаточно обновить вкладку.

## Работа

1. Выберите Low или Medium слева. По умолчанию открывается каталог Low; для Medium — макет входа.
2. Измените организацию, название сервиса, заголовок или описание: результат сразу появляется справа.
3. Выберите демонстрационное состояние. Low: каталог, пустой архив, «Не найдено», материал недоступен. Medium: вход, ошибка входа, список файлов, просмотр файла, пустой каталог, истёкшая сессия.
4. В группе документов выберите один из шести файлов; измените название, путь, дату и текст. Для просмотра текста выберите Medium → «Просмотр файла». Выбор другого документа сразу меняет просмотр. Размер в каталоге считается по UTF-8-тексту.
5. В списке Medium нажмите название файла; «К списку файлов» возвращает каталог, «Выйти» показывает макет входа. Low отвечает статическим сообщением о недоступности материала.
6. Переключите ширину предпросмотра: по экрану, 1040, 760 или 390 px. Фактическая ширина ограничена доступным местом; для полного 1040 px нужен достаточно широкий экран.
7. «Сбросить пример» возвращает исходные тексты, документы, уровень, состояние и ширину. Перезагрузка также возвращает пример. Хранилища браузера не используются.

Пометка локального режима закреплена наверху и видна при прокрутке. В Medium вход не выполняется, серверная сессия не создаётся. Поля макета входа доступны только для чтения, кнопка отключена. Реальные формы, скачивание, серверный выход и псевдокоманды относятся к #3/#9.

Все сведения о вымышленной организации «Вереск» синтетические. Редактируемые строки показываются как текст, включая HTML/JavaScript. Пути документов — подписи, а не адреса запросов или файлов на диске. Предпросмотр находится в iframe с отдельными стилями и sandbox без разрешения выполнения скриптов; отображением управляет оболочка через DOM.

## Файлы

- `index.html`, `lab.css`, `lab.js` — оболочка, настройки, демонстрационные состояния.
- `templates/preview.html` — изолированная область предпросмотра.
- `templates/shared.js`, `low.js`, `medium.js` — компоненты отображения без API и хранилищ.
- `fixtures/example.js` — фабрика независимой копии PreviewModel с шестью синтетическими файлами; `fixtures/documents/` содержит их исходные текстовые копии для сверки. Источник данных браузера — фабрика, не файлы на диске.
- `assets/archive.css` — общий стиль обеих приманок.
- `assets/screenshots/` — браузерные снимки экранов; `assets/verification.json` и `assets/QA.md` — фактические результаты проверки.
- `INTEGRATION.md` — внутренняя модель, обработчики и граница будущего подключения.

## Воспроизводимая ручная приёмка

- Открыть лабораторию без запуска Go. Проверить все четыре состояния Low и шесть состояний Medium.
- Для каждого документа открыть Medium → просмотр, сверить название, путь, дату, текст с редактором; проверить возврат и демонстрационный выход.
- Вставить `<img src=x onerror=alert(1)>` в каждое текстовое поле, включая содержимое документа. Должен появиться буквальный текст; изображения, диалоги и запрос `x` не появляются.
- Изменить несколько полей и ширину; нажать сброс, затем отдельно изменить данные и перезагрузить вкладку. Должен восстановиться исходный пример.
- Проверить 1440×900, 1280×720 и узкий предпросмотр 390 px. Настройки прокручиваются; предпросмотр имеет собственную прокрутку. Пометка остаётся видна.
- Клавишами Tab / Shift+Tab перейти по элементам. Радиокнопки переключаются стрелками, списки — стрелками, кнопки — Enter/Space. Проверить видимый фокус и возврат фокуса к заголовку при действиях внутри предпросмотра.
- В инструментах браузера проверить Console и Network: ошибок нет, загружаются только статические файлы с локального адреса; нет API HoneyForge, внешних ресурсов и сетевых шрифтов.

Обязательные проверки основного репозитория (его исходники эта задача не меняет):

```sh
go build ./...
go vet ./...
```

Самостоятельная лаборатория не доказывает готовность #3, #7 или #9. Сохранение профиля, права, реальные маршруты, сессии, fake-FS и доставка событий здесь отсутствуют.
