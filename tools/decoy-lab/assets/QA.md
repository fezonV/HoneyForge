## Артефакты и качество свидетельств

`verification.json` содержит фактические функциональные утверждения, пустой журнал ошибок и перечень 66 снимков: 30 верхних, 30 нижних, 3 промежуточных узких, 3 для оболочки/редактора/фокуса. Сигнатуры JPEG и размеры проверены; снимки новее последней правки UI. Снимки служат свидетельством отрисовки, а не заменяют DOM интерфейса.

Первый проход выявил ошибку захвата: Home/End и непосредственный screenshot не гарантировали нужную прокрутку и завершённую отрисовку. Первые снимки с подписью bottom были неполными. Они заменены: настоящий футер прокручивается в видимую область через браузерный click; после свежего AX-снимка используется ожидающий screenshot. Для длинных каталогов добавлены промежуточные кадры. Исходники ради исправления свидетельств не менялись.

`family-comparison.json` получен командой:

```sh
node /Users/dalexisse/.codex/skills/visual-qa/scripts/visual-qa.mjs image-diff tools/decoy-lab/assets/low-catalog-comparison.png tools/decoy-lab/assets/medium-files-comparison.png
```

JPEG были преобразованы в PNG через `sips` для этого инструмента. Результат: размеры совпадают, alpha intact, diffRatio 0.1834, similarity 82. Это сравнение **разных** Low/Medium-состояний, не тест на совпадение с референсом. Отличия ожидаемы: выбранный уровень/состояние, пояснение, logout, высота header и вертикальное положение строк. Точного внешнего визуального референса в задаче нет.

Механический Impeccable detector запущен один раз. Вернул `[]` в degraded regex-режиме из-за отсутствия HTML parser modules; вычисленный контраст/селекторы этим результатом не подтверждаются. UI дополнительно проверяется независимым визуальным обзором.

Финальная проверка целостности также независимо подтвердила сигнатуры, размеры, уникальность и свежесть всех снимков. Обзор функциональной целостности сверял сценарии с исходниками и доказательствами; браузерные действия повторно независимыми проверяющими не запускались.

Дополнительная локальная проверка Node подтвердила: 6 уникальных ID, принадлежность документов разделам, точное совпадение каждого `fixtures/documents/*.txt` с body фабрики и независимость двух вызовов `createExample()`.

## Ограничения

- Проверен Chromium встроенного браузера. Другие браузеры отдельно не проверялись.
- Серверных сессий, API, доставки событий, скачивания и реальных действий здесь нет: это заявленная граница issue #18.
- Автоматических тестов Go в текущем репозитории нет; для этой задачи выполнены сборка, vet и живой браузерный сценарий.
- На небольшом экране длинный контент имеет собственную прокрутку iframe. Полная ширина 1040 px требует соответствующего места в окне.
